1. 背景与目标

问题

一个 iOS 开发者（同时也做跨平台、全栈工作），每天打开电脑面对空白浏览器首页，需要手动打开一堆开发工具（Xcode、终端、各种文档）、切换项目上下文、找零散的代码片段、追踪学习进度。信息分散在各处，切换成本高。

产品决策

将"通用桌面启动页"重定义为程序员的效率中枢——聚合开发工具箱、项目管理、任务面板、学习追踪和代码片段，所有程序员每天都要用的高频操作集中在一张页面上。

排除的

  • 番茄钟 — 与工作节奏不匹配，程序员是任务驱动而非时间切块驱动
  • 天气 — 与开发工作无关
  • 习惯追踪 — 非程序员专属，过度设计
  • 快速笔记 — 改为更聚焦的代码片段模块

4. 核心流程

启动

浏览器加载页面 → 读取 localStorage 中所有持久化数据 → 渲染各模块 UI → 状态栏时钟启动 → 工具箱就绪。

每日路径

典型路径 A：开始一天

  1. 打开浏览器 → 看到状态栏时间 + 活跃项目
  2. 点击项目 → 跳到 GitHub/Xcode
  3. 从任务面板勾选完成项
  4. 用工具箱处理数据（JSON 格式化等）

典型路径 B：中断时

  1. 在代码中发现一个好片段 → 打开 Snippets 模块
  2. 粘贴代码 → 选语言 → 保存
  3. 下次需要时搜索找到

5. 功能需求

FR-01状态栏 Status Bar

Purpose

程序员一眼能看到当前时间、Unix 时间戳、星期几——开发调试时频繁用到。

Layout

17:22 · 2026-11-19 · Thursday
1763544167 [复制]

Processing Rules

  • 时钟每秒刷新，24 小时制显示 HH:MM:SS
  • Unix 时间戳 = Math.floor(Date.now() / 1000)
  • 点击时间戳复制到剪贴板，弹出 "Copied ✓" 提示 1 秒后消失
  • 日期显示格式：YYYY-MM-DD · Weekday · 第 N 周

Interaction

  • 点击时间戳 → 复制
  • 悬停时显示完整 ISO 时间字符串

Purpose

程序员每天可能在 2-5 个项目间切换。这个模块聚合所有活跃项目，展示技术栈、当前待办数、快速打开入口。

Purpose

高频开发小工具，覆盖 iOS/Swift 开发者最常用的几个场景。纯客户端，无需网络。

Layout

JSON

↓ 点击上方 tab 切换，下方为工具内容区

工具清单

工具输入输出说明
时间戳日期 或 Unix int相互转换 + ISO 格式iOS 开发调试必备
JSON原始 JSON 字符串格式化 / 压缩 / 验证一键美化 + 错误行定位
正则pattern + test string匹配结果高亮 + 捕获组JS RegExp 语法
ColorHEX / RGB / Swift Color相互转换输出 Swift UIColor(red:,green:,blue:) 代码
Base64原始字符串Encode / Decode—
Hash字符串MD5 / SHA1 / SHA256纯客户端实现

Processing Rules

  • 工具切换使用一个容器，只渲染当前激活的工具
  • 所有输入框都有「清空」和「复制结果」按钮
  • 工具状态（当前 tab、输入值）不持久化，刷新即重置
  • JSON 格式化错误时，在下方红色提示具体行列号
  • Color 转换：HEX #RRGGBB → RGB(255,0,128) → UIColor(red:1.0, green:0, blue:0.5, alpha:1.0)
  • 正则：实时匹配（oninput），高亮匹配文本，显示所有捕获组

Color 转换示例输出

输入：#FF6B9D

输出：UIColor(red: 1.0, green: 0.42, blue: 0.62, alpha: 1.0)

输出：CGColor → 255, 107, 157

FR-04任务管理 Task Board

Purpose

按项目分组的 Todo 列表。程序员的任务天然归属某个项目——跨项目混合的 flat list 太混乱。

Layout

任务面板
＋ 添加任务
📱 iOS-App · 3 项待办
· [ ] 实现登录流程
· [ ] 修复 #123 crash
· [x] 添加单元测试
🌐 Web-Dashboard · 1 项待办
· [ ] 部署到生产环境

Fields

字段类型说明
projectIdref归属的项目（必填）
titlestring任务内容
doneboolean完成状态
priorityenumlow / medium / high（可选）
createdtimestamp自动生成

Processing Rules

  • 任务按 projectId 分组，组内按优先级 → 创建时间排序
  • 勾选/取消勾选 → 实时保存，项目卡片上的"待办数"联动更新
  • 新增任务时必须选择归属项目（从已有项目下拉选择）
  • 完成的任务默认折叠到"已完成"区域，点击展开
  • 批量操作：一键清除所有已完成项

States

无项目时添加任务 → 弹出 "请先创建项目" 的引导 → 跳转项目模块的添加按钮
项目删除 → 确认弹窗中提示 "将同时删除该项目下所有任务"，勾选确认后才执行

FR-05代码片段 Snippets

Purpose

开发中经常发现好代码想保存——比如 Swift 扩展、正则表达式、Xcode 配置。这个模块就是个人代码片段库。

Layout

代码片段
🔍 搜索
＋ 新建
UIColor Extension swift iOS, color
extension UIColor {
  convenience init(hex: UInt32) { ... }
}

Fields

字段类型可选值
titlestring—
codestring多行文本
languageenumswift / objective-c / python / javascript / typescript / shell / html / css / other
tagsstring[]自由标签
createdtimestamp自动生成

Processing Rules

  • 搜索框对 title + tags 做实时模糊匹配（大小写不敏感）
  • 语言标签用不同颜色展示（swift=橙, python=蓝, shell=灰…）
  • 点击片段 → 展开预览，显示完整代码（等宽字体）+ 一键复制
  • 代码区不做语法高亮（MVP 阶段），但保留 language 元数据
  • 空状态提示："还没有片段，把好代码存下来吧"

FR-06学习追踪 Learning

Purpose

程序员需要持续学习。这个模块追踪"正在学习的技术"，不是番茄钟式的打卡，而是简单的进度追踪。

Layout

学习追踪
＋ 添加
Swift Concurrency · ⭐⭐☆☆☆ · 3 / 5 章节

Fields

字段类型说明
titlestring技术名 / 课程名
categoryenumiOS / Frontend / Backend / DevOps / Other
progress0-100百分比，手动更新
priority0-5星数，表示当前关注度

Processing Rules

  • 按 priority 降序排列，priority 相同按 progress 降序
  • 进度条颜色渐变：0→灰, 30→紫, 70→天蓝, 100→绿
  • 点击星标切换 priority（0→1→2→3→4→5→0 循环）
  • 完成（progress=100%）的条目自动移到"已掌握"区域，灰显
  • 不做任何自动追踪，完全手动更新——MVP 保持简单

6. 共享规则

存储

  • 所有持久化数据通过 localStorage 存储，key 前缀 dev_
  • 每次写操作后立即同步，无 debounce（避免数据丢失）
  • 空数据安全：任何模块 localStorage 为空时展示默认预置或引导文案

键盘快捷键

快捷键动作
Esc关闭任何打开的 Modal
/（focus 在 Snippets 时）聚焦搜索框
Enter（表单内）提交表单

确认弹窗

  • 所有删除操作必须有确认弹窗
  • 批量删除项目关联的 Task 时，弹窗内容必须显式提及 "将同时删除 N 个任务"

响应式

  • ≥ 1024px：3 列网格，Project/Tool/Snippets 三栏并列
  • 640–1023px：2 列网格，任务面板跨两列
  • ≤ 639px：单列堆叠

无障碍

  • 所有可交互元素有可见的 focus ring
  • 支持 prefers-reduced-motion，禁用非必要动画
  • 颜色对比度 ≥ WCAG AA（4.5:1）
