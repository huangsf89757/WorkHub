# 任务扩展

> 状态：✅ 已实现 · 首个真实业务扩展，后续扩展的参考样板
> 实现文件：`js/ext-todo.js` · 注册：`main.js` 顶部 import 一次

## 1. 定位

分组待办管理。验证"扩展契约 + 通用 DAO + 同步元数据 + 五区渲染 + 界面样式挂载"端到端可用，同时作为新扩展的实现范本。

## 2. 扩展契约

通过 `registry.add({...})` 自注册，五个钩子全部实现：

| 钩子 | 渲染区 | 内容 |
|---|---|---|
| `badge()` | left / top 导航 | 未完成任务数（0 时不显示） |
| `home(ctx)` | center | 主列表：统计卡片 + 视图切换 + 工具栏 + 分组任务|
| `detail(id, ctx)` | center | 单个待办编辑：标题/优先级/开始时间/截止日/分组/标签/备注/完成态 |
| `badge()` | left/top | 未完成任务数（0 时不显示） |

统计卡片（待完成/已完成/已逾期/完成率 + 分组分布 + 逾期摘要）直接渲染在 center 主页顶部；四边侧栏只挂扩展入口，不显示详情内容。

注册元数据：`id='todo'`、`order=1.9`、`group='main'`、`mounts=['left']`、`icon=icons.todo`。

## 3. 数据域

```
declareDomain('todos', [])
declareDomain('todoGroups', [])
```

**todo 记录结构：**

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | `uid()`（crypto.randomUUID） |
| `title` | string | 标题 |
| `done` | boolean | 完成态 |
| `completedAt` | number\|null | 完成时间戳；标记完成写入、取消时清空（v8；历史数据近似值） |
| `priority` | 'high'\|'medium'\|'low' | 优先级 |
| `start` | number\|null | 开始时间戳（ms） |
| `due` | number\|null | 截止时间戳（ms） |
| `note` | string | 备注 |
| `tags` | string[] | 标签 |
| `groupId` | string | 所属分组 id（恒指向一条真实分组记录；无虚拟"默认/未分组"） |
| `created` | number | 创建时间戳 |
| `meta` | object | `{updatedAt, updatedBy, deletedAt, rev}`（DAO 自动维护） |

**todoGroup 记录结构：** `{ id, name, sort, created, meta }`（v8：`sort` 为记录字段可随 LWW 同步，`created` 稳定不随保存刷新）。

分组表 v8 起为完整同步表（四同步列齐备，与待办表对齐）；删除走 `remove()` 软删除墓碑（写 `deleted_at`，由列作为真相源），刷新后不复活。所有分组均为真实记录，无虚拟"默认/未分组"：初始 0 分组，首次新建任务时自动创建名为"默认"的真实分组并归属；删除分组时**连带软删组内全部待办**（二次确认提示数量，不可撤销）。

## 4. 视图与交互

主视图三个 tab：**全部 / 未完成 / 已完成**。
- 全部：所有存活待办，按分组归类，组内按"未完成优先 + 优先级"排序
- 未完成：`done === false`
- 已完成：`done === true`

初始状态为空：不注入任何示例分组或待办（2026-11-25 起）。用户可在扩展中心启用 任务后自行创建数据。存量工作台通过一次性重置迁移（localStorage 标记 `wh_sys_settings_reset_v1`）自动清空旧数据。

**交互入口：**
- 工具栏「新建」下拉：新建任务/ 新建分组；右侧「排序」「分组」下拉切换视图维度
- 视图 tab：全部 / 未完成 / 已完成
- 每行：圆形复选框切换完成、标题进入详情、优先级色点、标签、开始/截止日、创建时间、删除
- 新建任务统一走工具栏「新建」下拉，在弹窗中选择分组；分组默认值为上次创建任务时选中的分组（`wh_sys_settings_todoLastGroupId` 偏好，刷新后仍保留），该分组已删除时回退第一个分组
- 分组标题右侧「⋯」：重命名 / 删除；删除时连带删除组内待办（二次确认提示数量）
- 新建任务弹窗与待办详情共用字段布局：标题 → 开始时间 / 截止日期（同行）→ 分组 / 优先级（同行）→ 标签 → 备注
- **表头行**（仅自定义分组视图）：tab 下方显示「标题 / 开始时间 / 截止时间 / 创建时间」列标题，与任务行严格对齐；窄屏只保留截止列
- **拖动**（仅「分组：自定义分组」视图）：所有分组（含"默认"）标题行可拖动排序；任务行可拖到其他分组；排序/归属变更走 LWW 同步。基于 SortableJS（vendor 本地文件），桌面可用、移动端暂不支持
- 标签为胶囊组件：回车或逗号添加、点 × 或空输入退格删除；详情中增删即时保存
- 详情备注：500ms 防抖 + blur 提交，避免输入时全量重绘打断焦点
- 统计信息在 center 主页顶部卡片中展示，随数据变更实时刷新；不再使用右栏开关或底部状态条

## 5. UI 设计（参考飞书任务后精简）

借鉴飞书任务视图的分组卡片与列式信息，按实际使用精简交互：

| 元素 | 说明 |
|---|---|
| 工具栏 | 仅三项：新建（下拉「新建任务/ 新建分组」）、排序、分组；无下拉三角 |
| 列式信息 | 行内展示开始时间 / 截止时间 / 创建时间，窄屏只保留截止列；不设独立表头行；单用户场景不展示创建人 |
| 分组折叠 | 每组可折叠，头显计数，无下划线 |
| 分组管理 | 分组标题右侧「⋯」下拉：重命名 / 删除（危险项标红，连带删组内待办）；无虚拟分组 |
| 任务新建 | 统一在工具栏「新建 → 新建任务」弹窗中选择分组 |
| 新建弹窗 | 开始/截止日期同行、分组/优先级同行；标签为可增删胶囊，与详情字段结构统一 |
| 已移除 | 独立「新建分组」按钮、筛选与字段配置按钮、分组 chip 筛选行、列式表头、底部快速添加框 |

创建分组统一走工具栏「新建」下拉，避免两个入口并存。

## 6. 依赖

## 7. 界面样式适配

- 经典分栏：左侧导航项 + center（统计卡片 + 列表）；四边侧栏只挂扩展入口，详情统一在中间区
- 3D 工作室：默认挂在"电脑"实物（`defaultExt: 'todo'`），点击进真实 任务页并带返回舞台条
